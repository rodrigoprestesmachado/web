Code:

function inOrder(node) {
if (node === null) return;
inOrder(node.left);
visit(node);
inOrder(node.right);
}

Explanation

In-Order Traversal is a method of traversing binary trees that follows the order:

  1. Visit the left subtree
  2. Visit the current node
  3. Visit the right subtree
