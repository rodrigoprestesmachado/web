## Badge creator

The badge creator is a free tool that allows you to create custom badges for
your projects. It is useful for showcasing your achievements, skills, or
certifications.
{: .fs-3 }

Available at this link: [badge](https://rpmhub.dev/tools/badge.html)
{: .fs-3 }

## Compress PDF

The PDF compressor is a free tool that allows you to reduce the size of PDF
files without losing quality. It is useful for optimizing documents for sharing
or storage.
{: .fs-3 }

Available at this link: [compressor](https://rpmhub.dev/tools/pdf.html)
{: .fs-3 }
